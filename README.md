# 🌴 RioTour - Landing Page de Turismo

Landing Page desenvolvida durante estudos de HTML5 e CSS3, com foco na criação de interfaces modernas, estrutura semântica e responsividade.

## 📸 Preview

Projeto desenvolvido para apresentar pontos turísticos do Rio de Janeiro de forma elegante e intuitiva.

## 🚀 Tecnologias

- HTML5
- CSS3

## ✨ Funcionalidades

- Estrutura HTML semântica
- Layout responsivo
- Hero Section
- Imagem principal com legenda
- Cards de atrações turísticas
- Design moderno
- Navegação por âncoras

## 🎯 Objetivo

Praticar conceitos fundamentais de desenvolvimento Front-end através da criação de uma Landing Page de turismo.
